🔔 푸시 빌더 — 텔레그램 없이, 앱을 닫아도 알림을 받는 "나만의 푸시 앱"을 만듭니다. 앱 정보만 입력하면 수신 PWA · 서버리스 발송 함수 · VAPID 키가 든 완결 프로젝트를 통째로 내려받아 Vercel에 무료로 배포할 수 있고, 내가 만든 다른 웹앱들이 이 앱으로 알림을 쏘도록 연동할 수 있습니다. 서버는 필요 없습니다(Vercel 서버리스 + Firestore).
1 앱 정보 입력→ 2 프로젝트 ZIP 받기→ 3 Vercel 배포 + 환경변수→ 4 폰에 설치 → 알림 켜기→ 5 다른 앱에서 발송 연동
① 내 푸시 앱 정보
#2563eb
② 보안 키 생성됨
🔑 이 앱 전용 VAPID 키와 발송 키(APP_KEY)가 이 브라우저에서 자동 생성되었습니다. 공개키는 앱에 자동 포함되고, 비공개키·발송키는 오른쪽 「환경변수」 탭에서 Vercel에 넣습니다.
③ 프로젝트 내려받기
📦 수신 PWA + 서버리스 함수 + 아이콘까지 든 완성 프로젝트 ZIP을 받습니다. 압축을 풀어 그대로 Vercel에 올리면 됩니다.
생성 결과
Vercel 프로젝트 → Settings → Environment Variables에 아래 5개를 등록하세요. FIREBASE_SERVICE_ACCOUNT만 Firebase에서 받은 JSON(한 줄)이고, 나머지는 아래 값을 그대로 씁니다. 🔒 비공개키·발송키는 남에게 공개하거나 깃에 올리지 마세요.
