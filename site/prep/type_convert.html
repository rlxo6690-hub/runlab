로그 변환(Log Transformation)은 우편향(오른쪽 꼬리) 분포를 대칭 분포에 가깝게 만드는 대표적 타입 변환 기법입니다. 소득·인구·주가처럼 몇 배씩 차이 나는 데이터에 적용하면 스케일을 압축하고 선형 모델·통계 검정의 가정을 충족시킵니다. 프리셋을 선택하거나 직접 입력해 ln(x), log₁₀(x), log(1+x) 세 방법을 비교하세요.
데이터 입력
변환 결과 비교

원본 데이터
Original
변환 없음 — 있는 그대로
값 그대로. 우편향이 클수록 큰 값이 분포를 압도해 패턴이 묻힙니다.
자연 로그
ln(x)
x' = ln(x)  ·  x > 0 필수
밑이 e인 로그. 통계·ML에서 가장 널리 사용. 1→0, 100→4.6
상용 로그
log₁₀(x)
x' = log₁₀(x)  ·  x > 0 필수
밑이 10인 로그. 값이 자릿수로 해석됨. 10→1, 1000→3
로그1p
log(1+x)
x' = ln(1+x)  ·  x ≥ 0 허용
0 포함 데이터에 안전. 0→0 매핑. 카운트·조회수에 최적
📐 왜도(Skewness) 변화 — 변환이 분포를 얼마나 대칭으로 만드나

왜도는 분포의 치우침 정도입니다. |왜도| < 0.5면 대칭, 1 이상이면 뚜렷하게 치우친 분포입니다. 로그 변환이 왜도를 0에 가깝게 줄일수록 선형 모델의 가정을 더 잘 충족합니다.

변환값 상세 비교
음수·0값은 ln/log₁₀에서 NaN 처리

언제 어떤 로그 변환을 쓸까?
ln(x)
자연 로그 — 통계·ML 표준
x' = ln(x) = log_e(x)
✅선형회귀·GLM의 종속변수 변환
✅소득·GDP·부동산 가격 데이터
✅성장률·수익률 등 곱으로 표현되는 데이터
⚠️x ≤ 0이면 undefined — 음수/0 주의
선형회귀 경제데이터 GLM
log₁₀(x)
상용 로그 — 자릿수 해석
x' = log₁₀(x)
✅지진 규모(리히터), 소음(dB)
✅pH, 별의 밝기(등급) 데이터
✅시각화 축에서 자릿수 단위 표현
⚠️값이 10의 배수가 아닐 때 해석 주의
지구과학 물리학 시각화
log(1+x)
로그1p — 0 포함 데이터
x' = ln(1 + x)
✅조회수·구매 횟수·리뷰 수 (0 포함)
✅자연어 처리에서 TF 변환
✅희소 카운트 데이터 전처리
⚠️x < −1이면 undefined
