# RunLab 배포 안내서 (가비아 클라우드 서버)

> 대표님이 그대로 따라 하실 수 있게 만든 안내서. 코드 몰라도 됩니다.
> **도메인 = 호스팅케이알 / 서버 = 가비아.** 서버에서 **명령어 몇 줄**만 붙여넣으면 끝.
> 막히면 저(클로드)한테 그 화면 그대로 보여주시면 이어서 안내합니다.

---

## 준비물 두 개 먼저 사기

### 1) 도메인 — 호스팅케이알
- hosting.kr 에서 **runlab.kr** (또는 원하는 주소) 구매.
- 아직 **DNS 연결은 나중에** 합니다(4단계). 지금은 사두기만.

### 2) 서버(VPS) — 가비아
- 가비아(gabia.com) → **서버호스팅 → 클라우드 서버(g클라우드 / 가상서버)** 구매.
- ★ **root 권한이 되는 리눅스 클라우드 서버**로 고를 것(도커 설치해야 함). 관리형·제한형 상품 말고 일반 클라우드/VPS.
- **컴퓨팅 → 서버 → Gen2 → Micro** 선택:
  - **사양: 1vCore / RAM 2GB** (제일 저렴, 스왑으로 보강)
  - **운영체제: Ubuntu 22.04 LTS (무료)**
  - **스토리지: 50GB** (가능한 최소)
  - **요금: 시간 과금(무약정)** — 강의 안 할 땐 서버 정지하면 시간만큼만 냄
- 나중에 버벅대면 콘솔에서 4GB로 올리면 됩니다(5분).
- 구매하면 가비아가 **서버 IP 주소**(예: `123.45.67.89`)와 **root 접속 비밀번호**를 줍니다(콘솔에서 설정). 이 둘을 메모.

---

## 3) 서버에 접속하기 (SSH)

- **맥**: 기본 "터미널" 앱 열고 →  `ssh root@서버IP`  입력, 비밀번호 입력.
- **윈도우**: 가비아 콘솔의 웹 접속(SSH 콘솔)을 쓰거나, 무료 프로그램 "PuTTY"로 접속.
- 접속되면 검은 화면에 글자 입력할 수 있게 됩니다. 여기에 아래 명령들을 **한 줄씩 붙여넣고 엔터**.

---

## 4) 도메인을 서버에 연결 (DNS)

호스팅케이알 관리 화면 → 내 도메인(runlab.kr) → **DNS/네임서버 설정** → **A 레코드** 추가:

| 종류 | 호스트 | 값 |
|---|---|---|
| A | @ (또는 비워둠) | 가비아 서버 IP |
| A | www | 가비아 서버 IP |

- 저장 후 **10분~1시간**쯤 지나면 연결됩니다(전파 시간).

---

## 5) 서버에 프로그램 설치 (Docker)

서버 접속 화면에 아래를 **통째로 복사해 붙여넣고 엔터**:

```bash
curl -fsSL https://get.docker.com | sh
```

끝나면 Docker가 깔립니다(1~2분).

---

## 5-1) 메모리 여유 만들기 (2GB 서버 필수)

2GB 서버는 빠듯해서, 디스크를 여유 메모리(스왑)로 4GB 빌려줍니다. 아래 통째로 붙여넣기:

```bash
sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile && echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

이러면 무거운 작업(머신러닝·PPT변환)이 몰려도 잘 안 죽습니다.


---

## 6) RunLab 소스 올리기

방법 A — **깃허브에 올려두고 받기**(추천, 제가 도와드림):
```bash
git clone <RunLab 저장소 주소> runlab && cd runlab
```

방법 B — **압축파일 올리기**: 대표님 폴더(`dataforge-복구`)를 zip으로 서버에 올린 뒤 압축 해제하고 그 폴더로 이동.

---

## 7) 설정 파일(.env) 만들기

```bash
cp .env.example .env
```

`.env` 를 열어(`nano .env`) 값을 채웁니다:
- `SITE_DOMAIN` / `ALLOWED_HOSTS` → 산 도메인 (runlab.kr)
- `ADMIN_PASSWORD` / `DEMO_PASSWORD` → 강한 비밀번호로
- `SECRET_KEY` → 아래 명령으로 만들어서 붙여넣기:
```bash
docker compose run --rm app python -c "from django.core.management.utils import get_random_secret_key as k; print(k())"
```
(나온 긴 문자열을 `.env`의 SECRET_KEY 자리에 붙여넣기. `nano`는 저장 = Ctrl+O 엔터, 종료 = Ctrl+X)

---

## 8) 실행 — 이거 한 줄이면 끝

```bash
docker compose up -d --build
```

- 처음엔 프로그램들(글자인식·PPT변환·영상·머신러닝) 설치하느라 **5~15분** 걸립니다. 기다리면 됩니다.
- 끝나면 **https://runlab.kr** 로 접속 → RunLab이 뜹니다. 자물쇠(HTTPS)도 자동으로 붙습니다.

---

## 확인 / 관리

- **잘 떴나 보기**: `docker compose ps` (state가 running 이면 정상)
- **로그 보기**: `docker compose logs -f app`
- **관리자 접속**: `https://runlab.kr/admin/` → `.env`에 넣은 ADMIN_PASSWORD
- **교육 세션 만들기**: 관리자 → 세션 생성 → **교육 코드** 발급 → 학생에게 `https://runlab.kr/lms/` 주소와 코드 전달
- **끄기/켜기**: `docker compose down` / `docker compose up -d`
- **업데이트**(소스 바뀌면): `git pull && docker compose up -d --build`

---

## 자주 막히는 곳

- **접속이 안 돼요**: DNS 전파(최대 1시간) 기다리기. `docker compose ps` 로 running 확인.
- **자물쇠(HTTPS)가 안 붙어요**: 도메인 A레코드가 서버 IP를 정확히 가리키는지, 80·443 포트가 방화벽에서 열렸는지 확인(가비아 콘솔의 방화벽/보안그룹에서 80·443 허용).
- **메모리 부족(변환·머신러닝이 느리거나 죽음)**: RAM 2GB면 4GB로 올리기.
- **막히면**: 그 화면을 저한테 그대로 보여주세요. 이어서 안내합니다.

---

## 강의 전 체크(운영 팁)

- **강의 15분 전**: 가비아 콘솔에서 서버 **시작(전원 ON)**. 도커가 자동으로 RunLab을 띄웁니다(1~2분). `https://runlab.kr` 열어 확인.
- **강의 끝나면**: 가비아 콘솔에서 서버 **정지(전원 OFF)** → 시간요금 절약. (데이터는 안 날아감)
- 관리자에서 **이번 강의용 교육 세션·코드**를 미리 만들어 두기.
- 스트리밍 데모 쓸 거면 관리자 → 운영 → 스트리밍에서 미리 한 번 테스트.
