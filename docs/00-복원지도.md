# DataForge 복원 지도 (마스터)

> dataforge.ai.kr = 남기태(태태)의 데이터·AI 실습 교육 플랫폼. 강의 실습 교보재로 쓰던 사이트.
> 서버 백엔드 원본 소실 → 살아있는 프론트를 전수 회수하고 기능을 역설계한 재건 명세.
> 작성 2026-08-24. 섹션 상세는 `docs/inventory/*.md`. 근거표는 `docs/_backend-groundtruth.txt`.

## 회수 현황 [확인]

- 원본 사이트: PHP + openresty(nginx). 프론트 = 순수 HTML + 인라인 JS(빌드 없음). 콘모아와 같은 방식.
- **긁은 것: 245파일 / 10MB.** 사이트맵 78페이지 **전부**(누락 0), 각 페이지가 참조하는 JS·CSS·이미지·크롬확장 zip 3종까지.
- 저장 위치: `site/` (원본 그대로, 손대지 않음). 회수 스크립트: `tools/scrape.py`.
- 못 긁는 것 = 서버에서 도는 코드(PHP API·FastAPI·DB). 이게 재건 대상. 아래 백엔드 맵으로 계약 역설계 완료.

## 백엔드 API 맵 — 재건 대상 [확인, admin/index.php + 프론트 JS 역설계]

프론트가 `BASE_URL='/mfg'`를 붙이므로 `/api/X.php` == `/mfg/api/X.php` (같은 엔드포인트).

### A. mfg 공용 API 패밀리 (18개) — 관리자 콘솔이 단일 참조본
| 엔드포인트 | 역할 | 재건 난이도 |
|---|---|---|
| traffic_log.php | 방문 로그 비콘 (거의 전 페이지, 세션당 1회). **없어도 도구 동작** | 하 |
| traffic_stats.php | 트래픽 집계 (admin) | 하 |
| reviews.php | 후기 GET목록/POST등록 (허니팟 필드). index 티커 + admin | 중 |
| feedback.php | 개선의견 POST (promo.js 모달, CSRF) | 하 |
| prompt_lib.php | 프롬프트 라이브러리 `?action=categories\|all`. **builder/prompt_lib 필수** | 중 |
| courses.php | 과정 관리 GET/POST (admin·교육) | 중 |
| content_lib.php | 컨텐츠 라이브러리 (admin) | 중 |
| sessions.php | 교육 세션 관리 POST/DELETE | 중 |
| db_write.php | 제조 데이터 DB 저장. **컬럼목록이 스키마 힌트** | 상 |
| drive.php | 드라이브(파일) 연동 | 중 |
| short_url.php | 단축 URL | 하 |
| upload_file.php / upload_pdf.php | 파일·PDF 업로드 | 중 |
| hub_tools.php | 허브 도구 목록 관리 | 하 |
| stream_state.php | **관리자→서버공유상태→다수뷰어 poll 팬아웃** (강의 실시간) | 상 |
| login.php / logout.php | 관리자·공개 인증 (세션쿠키) | 중 |
| grafana_queries.php | (mfg 대시보드) | 중 |

★ **함정(반드시 기억): 관리자 쓰기 API는 전부 `POST + FormData(_method 파트 + payload Blob) + X-CSRF-Token`.** 소스 주석에 "mod_security 우회"라고 대표가 직접 적어둠. 진짜 PUT/DELETE를 `_method` 필드로 위장. 이걸 모르고 재구현하면 관리자 기능 전부 깨짐.

## 재건 함정 모음 (섹션 인벤토리에서 추출) [확인]

1. **관리자 API `_method` mod_security 우회** — 위 A 참고. 최우선.
2. **stream_state.php 팬아웃** = 강의 실시간(교육생 화면 미러링)의 심장.
3. **자체호스팅 정적 에셋** — `/work/vendor/qpdf.js`+`qpdf.wasm`(pdf_unlock, 1.3MB), `/mfg/js/promo.js`(전 페이지 공통). 서버에 파일로 있어야 함.
4. **인라인 내장 데이터 보존** — `builder/boundary.html`에 시도/시군구 GeoJSON **490KB** 인라인. 반드시 살릴 것.
5. **proposal PDF 한글 누락** — pdf-lib 기본폰트라 한글이 조용히 빠짐(PNG는 정상). 한글폰트 embed 필요.
6. **CDN 버전 혼재** — Chart.js(4.4.0/4.4.3/무버전), SheetJS(cdnjs/jsdelivr/sheetjs-latest) 페이지마다 다름. 재현성 위해 고정 권장.
7. **스크랩 누락분(코드 새로 짜야)** — CSRF 실토큰 발급 로직, crawl_batch.php 본체, lms 콘텐츠 로직, DB 스키마 전체.
8. **index__*.html 30여 개는 중복** — 쿼리스트링별 저장본, 내용상 index.html 1개.

## 권장 재건 순서 (콘모아 방식 참고)

- **0. 지금 상태 = 회수·인벤토리 완료.** (이 문서)
- **1. 정적 63개 도구 먼저 세우기** — 긁은 것 그대로 정적 호스팅. 빠른 승리 + UI 재디자인 대상 확정.
- **2. mfg 공용 API 재구현** — admin/index.php 계약 기준. `_method` 규약·CSRF·세션. DB 스키마는 db_write 컬럼힌트로 시작.
- **3. FastAPI ML 서버** — ml/text/timeseries. 파이썬 재작성.
- **4. work 프록시** — ocr/youtube_dl/ppt. 외부 바이너리(yt-dlp/LibreOffice) 의존.
- **5. factory_lab + lms + 스트리밍** — 가장 무겁고 서버 상태 많음.
- **6. UI 전면 재디자인** — 기능 다 선 뒤 맨 마지막(콘모아 M7 교훈: 재디자인이 백엔드 구멍을 드러냄).
