← DataForge 홈
✈️ 텔레그램 봇 연결 도우미 — 봇 만들기부터 chat_id 자동 감지, 테스트 발송, 활용 코드 생성까지 5단계로 안내합니다. 가장 어려운 chat_id 찾기는 봇에게 메시지 한 번 보내면 자동으로 감지됩니다. 입력한 토큰은 서버로 전송·저장되지 않고 내 브라우저에서 텔레그램 API를 직접 호출하는 데만 사용됩니다.
1봇 만들기 — BotFather 진행
📱 텔레그램이 처음이라면 — 휴대폰에 텔레그램 앱을 설치하고 전화번호로 가입부터 하세요 (신규 가입은 앱에서만 됩니다). 가입만 돼 있으면 PC에서는 앱 설치 없이 웹 텔레그램으로 아래 과정을 전부 진행할 수 있습니다.
텔레그램의 공식 봇 생성기 BotFather에게 명령어를 보내 새 봇을 만듭니다. 이미 봇이 있다면 2단계로 바로 가세요.
✈️ BotFather 열기 휴대폰이라면 텔레그램 검색창에 @BotFather 검색
/newbot← BotFather 채팅창에 보내기
① 봇 이름을 물으면 아무 이름이나 입력 (예: 내 알림 봇)
② username을 물으면 영문으로 입력 — _bot으로 반드시 끝나야 합니다 (예: myalarm2026_bot). 이미 있는 이름이면 다시 물으니 숫자를 붙여보세요.
③ 성공하면 BotFather가 토큰을 줍니다 — 1234567890:AAH9x… 형태의 긴 문자열을 복사하세요.
🔐 토큰은 비밀번호와 같습니다. 토큰만 있으면 누구나 내 봇을 조종할 수 있으니 공개된 곳(GitHub 공개 저장소, 단톡방 등)에 올리지 마세요.
2토큰 확인 대기
복사한 토큰을 붙여넣으면 텔레그램에 직접 물어봐서 봇이 살아있는지 확인합니다.
3chat_id 자동 감지 대기
아래 버튼으로 내 봇과의 채팅을 열고 아무 메시지나 하나 보내세요 (예: 안녕). 이 페이지가 자동으로 감지해서 chat_id를 찾아드립니다.
✈️ 내 봇과 채팅 열기 휴대폰이라면 텔레그램 검색창에 @… 검색 → 시작 버튼 → 메시지 전송
💡 그룹 채팅의 chat_id가 필요하면: 그룹에 봇을 초대하고 그룹에서 아무 메시지나 보내면 그룹도 감지됩니다 (음수 id).
메시지를 기다리는 중… 봇에게 메시지를 보내면 여기에 나타납니다
4테스트 발송 대기
선택한 채팅으로 메시지를 보내 연결이 끝났는지 직접 확인합니다.
5활용 코드 받기 대기
내 토큰·chat_id가 채워진 완성 코드입니다. 그대로 복사해서 쓰거나, [🤖 AI 프롬프트]를 AI에게 붙여넣어 알림 기능을 만들어 달라고 하세요.
