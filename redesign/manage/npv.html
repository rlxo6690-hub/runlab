NPV (순현재가치) = 미래 현금흐름의 현재가치 합계 − 초기투자  |  IRR (내부수익률) = NPV = 0 이 되는 할인율
NPV > 0이면 투자 타당, IRR > 자본비용이면 채택 권고. 투자회수기간(Payback)·수익성지수(PI)도 함께 계산합니다.
기본 설정
초기투자금액 (원)
할인율 (자본비용, %)
10%
연도별 현금흐름 (유입)
총 미래 현금흐름 합계 : 0 원
분석 결과
NPV = Σ CFt / (1+r)t − 초기투자  |  IRR : NPV(r) = 0 인 r (이분법)  |  PI = PV(현금흐름) / 초기투자
