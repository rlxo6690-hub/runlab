🖼️ 이미지그랩 — 영역 이미지 저장은 웹페이지에서 영역이나 요소를 선택해 그 안의 이미지들을 원본 파일 그대로 저장하는 크롬 확장 프로그램입니다. 화면을 캡처하는 방식이 아니라 페이지가 쓰는 원본 이미지 파일을 그대로 받아오기 때문에 화질 손실이 없고, 찾은 이미지를 썸네일로 확인하며 원하는 것만 골라 한번에 저장할 수 있습니다.
이미지그랩 — 영역 이미지 저장
영역 드래그 · 요소 선택 · 썸네일로 골라 원본 그대로 한번에 저장
v1.0.0 Chrome · Edge 약 20KB 원본 화질
⬇ 다운로드 (ZIP)
🧩 설치 방법 — 한 번만 하면 됩니다
1
위 다운로드 버튼을 눌러 ZIP 파일을 받고 압축을 풉니다. 압축을 푼 폴더 위치를 기억하세요.
중요 폴더를 열었을 때 manifest.json 파일이 바로 보여야 합니다.
2
크롬 주소창에 chrome://extensions 를 입력해 이동합니다. (엣지는 edge://extensions)
3
오른쪽 위 「개발자 모드」 스위치를 켭니다.
4
「압축해제된 확장 프로그램을 로드합니다」를 클릭하고, 1단계에서 압축을 푼 폴더를 선택합니다. (manifest.json이 든 그 폴더)
5
목록에 「이미지그랩」이 추가되면 완료입니다. 🎉 툴바 퍼즐 아이콘(🧩)에서 📌 핀을 눌러 고정하면 편합니다.
🖼️ 사용 방법

이미지를 저장하고 싶은 페이지에서 툴바의 이미지그랩 아이콘을 클릭하면 두 가지 모드가 나옵니다.

⬚
영역 드래그
화면에서 사각형을 그리면 그 범위에 걸친 이미지들이 전부 수집됩니다. 갤러리·검색 결과·상품 목록에서 여러 장을 잡을 때 좋습니다.
🖱️
요소 선택
마우스를 올리면 기사·갤러리 같은 요소가 파란 테두리로 표시됩니다. 클릭하면 그 요소 안의 이미지가 전부 수집됩니다.
✅ 수집되면 오른쪽 아래에 썸네일 목록이 뜹니다. 썸네일을 클릭해 원하는 이미지만 선택/해제하고 ⬇ 저장을 누르면 선택한 이미지가 다운로드 폴더 안 imagegrab 폴더에 원본 그대로 한번에 저장됩니다. 취소하려면 ESC 키를 누릅니다.
💡 알아두면 좋은 점
  • 화면 캡처가 아니라 원본 이미지 파일을 그대로 저장합니다. 화면에 작게 보여도 원본이 크면 큰 해상도 그대로 받아집니다.
  • 화면에 보이는 부분을 그림으로 캡처하고 싶다면 자매 도구인 픽셀샷 — 영역 캡처를 사용하세요.
  • 같은 이미지가 여러 번 쓰였으면 한 번만 수집됩니다. 파일 이름은 원본 주소의 파일명을 따릅니다.
  • CSS 배경이미지·캔버스에 그려진 그림은 수집되지 않습니다. 이 도구는 페이지의 <img> 이미지를 대상으로 합니다. (배경/캔버스는 픽셀샷으로 캡처)
  • chrome:// 설정 페이지나 일부 보안 프레임(다른 도메인 iframe) 안쪽은 수집할 수 없습니다.
  • 저작권이 있는 이미지는 개인 학습·자료 정리 용도로만 사용하세요.
⚠️ 설치 후 크롬을 켤 때마다 「개발자 모드 확장 프로그램을 사용 중지하세요」 안내가 뜰 수 있습니다. 개발자 모드로 직접 설치한 확장에 크롬이 항상 보여주는 정상 안내이며, 「확장 프로그램 유지」를 누르면 계속 사용할 수 있습니다.
