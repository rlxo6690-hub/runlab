CSV 보간·병합 사용법 — 결측을 실제로 채우고 파일을 합치기

결측이 있는 진짜 CSV의 빈칸을 채우고(보간), 흩어진 여러 파일을 하나로 합치는 실전 도구입니다.

탭: 📊 데이터 보간 · 🔗 파일 병합

어떤 상황에서 쓰는 도구인가요

결측치·이상치 시뮬레이터가 '결측이 어떻게 생겼는지'를 보여주는 학습 도구였다면, 이 도구는 그다음 단계입니다. 실무에서 받은 진짜 파일을 올려서 빈칸을 실제로 채우고, 결과를 CSV로 내려받습니다. 센서 로그에 중간중간 값이 빠져 있어서 차트가 끊기거나, 월별로 쪼개진 매출 파일 열두 개를 하나로 이어붙여야 하는 상황 — 엑셀에서 빈칸을 하나씩 채우고 파일을 복사해 붙이던 반복 작업이 여기서는 클릭 몇 번으로 끝납니다.

중요한 특징이 하나 있습니다. 모든 처리는 브라우저 안에서 이뤄집니다. 올린 파일은 서버로 전송되지 않으므로, 고객 정보나 매출처럼 민감한 데이터도 외부 유출 걱정 없이 다룰 수 있습니다.

이 도구는 무엇을 하나요

CSV/XLSX를 업로드해 결측값이 있는 컬럼을 여러 개 선택하고, 8가지 보간 알고리즘 중 하나로 한 번에 채웁니다. 채워진 값은 차트와 미리보기에서 주황색으로 구분되어 어디가 바뀌었는지 바로 보입니다. 🔗 파일 병합 탭에서는 여러 파일을 세로 결합(행 이어붙이기) 또는 조인(키 컬럼으로 옆으로 합치기)으로 하나의 CSV로 만듭니다.

단계별 사용법

  1. CSV / XLSX 업로드 — 점선 영역에 파일을 드래그하거나 클릭해 올립니다. UTF-8·EUC-KR 인코딩을 자동 감지하고, 쉼표/탭 구분 CSV와 XLSX를 지원하며 행 수 제한이 없습니다. 엑셀에서 저장한 한글 CSV가 깨질까 봐 따로 변환할 필요가 없습니다.
  2. 보간할 컬럼 선택 — 업로드하면 숫자 컬럼이 알약 모양 버튼으로 나열됩니다. 전체 선택 · 결측 있는 컬럼만 · 전체 해제 버튼으로 한 번에 조절할 수 있어, 보통은 '결측 있는 컬럼만'을 누르면 끝입니다.
  3. 보간 알고리즘 고르기 — 8가지 중 하나를 선택합니다 — 평균값(Mean) · 중앙값(Median) · 전진채우기(Forward Fill) · 후진채우기(Backward Fill) · 선형 보간(Linear) · 스플라인(Spline) · 다항식(Polynomial) · 이동 평균(Moving Avg). 버튼을 누르면 아래에 방법 설명이 나타나고, 다항식은 차수를, 이동 평균은 윈도우 크기를 슬라이더로 조절합니다.
  4. 보간 실행 ▶ — 선택한 컬럼의 빈칸이 채워지고, 통계 타일과 컬럼별 보간 요약, 결과 시각화 차트가 나타납니다. 차트에서 점선은 원본(결측 포함), 주황 점은 보간으로 채워진 값입니다. 전체 미리보기 표에서도 보간된 값이 주황색으로 표시됩니다.
  5. ⬇ 보간 결과 CSV 다운로드 — 결과가 마음에 들면 채워진 데이터를 내려받습니다. 원본 파일은 그대로 두고 새 파일로 저장되니 안심하고 실험해도 됩니다.
  6. 🔗 파일 병합 탭 — 여러 파일을 한 번에 올리고 병합 방식을 고릅니다 — 세로 결합(Concat, 모든 파일의 행을 순서대로 쌓기 — 컬럼명이 다르면 빈 값으로 채우고 어느 파일에서 왔는지 표시하는 _source 컬럼이 추가됩니다) · 내부 결합(Inner Join) · 왼쪽 결합(Left Join) · 전체 결합(Outer Join). 조인을 고르면 결합 키 컬럼을 선택한 뒤 병합 실행 ▶을 누르고, 결과를 CSV로 다운로드합니다.
💡 주소 뒤에 #merge를 붙이면 파일 병합 탭이 바로 열립니다(보간 탭은 #interp). 교육 자료에서 특정 탭으로 바로 안내할 때 유용합니다.

결과를 읽는 법

주황색으로 표시된 값은 관측된 값이 아니라 알고리즘이 추정한 값입니다. 컬럼별 보간 요약에서 컬럼마다 몇 개가 채워졌는지 확인하고, 차트에서 주황 점들이 주변 흐름과 자연스럽게 이어지는지 눈으로 검증하세요. 시간 순서가 있는 데이터라면 선형 보간이나 스플라인이 흐름을 잘 따라가고, 순서가 의미 없는 데이터라면 평균값·중앙값이 무난하며, 센서처럼 '마지막 값이 유지된다'고 볼 수 있는 데이터는 전진채우기가 자연스럽습니다.

어떤 방법이 내 데이터에 맞는지 확신이 없다면, 결측치·이상치 시뮬레이터의 보간 탭에서 방법별 정확도(RMSE)를 비교하며 원리를 먼저 익혀보는 것을 추천합니다. 병합에서는 결과 행 수를 눈여겨보세요 — 내부 결합의 행 수가 원본보다 크게 줄었다면 키 컬럼 값이 양쪽에서 일치하지 않는 행이 많다는 신호입니다. 보간이든 병합이든 결과를 내려받기 전에 미리보기 표를 한 번 훑어보는 습관이 실수를 크게 줄여줍니다.
